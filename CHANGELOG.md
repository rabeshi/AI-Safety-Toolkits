# Changelog

## 0.3.0 — 2026-10-30

- Added a Foundations section with a four-stage study roadmap and pages on why AI might be dangerous, key
  alignment concepts, how safety is built into models, interpretability in depth, governance and policy, and
  courses, reading, and community.
- Added 10 resources (R083–R092): MASK, SAD, ControlArena, TransformerLens, nnsight, SAELens, Neuronpedia,
  WildGuard, Llama Guard, and CoCoNot, in three new categories (AI control, interpretability, safety classifiers).
- The AI control and interpretability method pages now list catalogue toolkits.

## 0.2.0 — 2026-10-30

- Added a documentation website (MkDocs Material) with a GitHub Pages deployment workflow.
- Added 15 beginner-friendly evaluation-method guides, including dangerous capabilities, alignment and propensity,
  AI control, interpretability, privacy, multimodal safety, and scoring.
- Added six step-by-step tutorials. New examples: a refusal eval with an LLM judge, a judge-agreement
  calculator, and a prompt-injection agent test.
- Every resource now has separate `paper_url`, `code_url`, `docs_url`, and `dataset_url` fields, verified
  against arXiv, GitHub, and Hugging Face.
- Added copy-paste quickstarts for 34 resources and method tags for 79.
- Rewrote the README, getting-started material, and guides for newcomers.
- Fixed scripts to read and write UTF-8 explicitly, so they behave the same on Windows.

## 0.1.0 — 2026-10-27

- Added 82 primary-source-reviewed resources across 17 navigation categories.
- Preserved and clarified all 25 entries from the original resource list.
- Added learning paths, professional evaluation guidance, templates, catalogue utilities, and teaching examples.
- No external benchmark execution or model comparison is claimed in this release.
