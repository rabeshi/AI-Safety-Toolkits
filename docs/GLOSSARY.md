# Glossary

| Term | Plain-language explanation |
| --- | --- |
| Agent | A system that uses model outputs to choose actions, often with tools and repeated steps |
| Alignment data | Data used to shape model behavior; it is not automatically an independent test set |
| Attack budget | The number of attempts, tokens, time, or compute allowed to an attacker |
| Benign control | A legitimate task used to check useful capability and avoid misreading inability as safety |
| Calibration | Checking whether a score, confidence estimate, or judge behaves reliably for its intended use |
| Construct validity | Whether an evaluation actually measures the concept it claims to measure |
| Contamination | Test information appearing in training or development data in a way that compromises independence |
| Direct prompt injection | An instruction supplied directly to redirect a system against its intended constraints |
| Indirect prompt injection | A malicious instruction arriving through external material, such as a document or tool response |
| Jailbreak | An attempt to elicit behavior that bypasses the target's intended safety constraints |
| LLM-as-judge | A language model applying a rubric to another system's output or behavior |
| Over-refusal | Declining a request that should be answered under the evaluation policy |
| Refusal consistency | Stability of refusal decisions across specified variations of a request |
| Sandbox | An isolated execution environment with defined boundaries and permissions |
| Scorer | Software or a procedure that turns observed behavior into an evaluation result |
| Solver | In Inspect, a component describing how a model or agent attempts a task |
| Threat model | A specification of attacker goals, access, knowledge, and resources |
| Trajectory | The sequence of observations, model messages, tool calls, and outcomes in an agent run |
| Utility | How effectively a system performs legitimate tasks |
